# Glossary

**Approval Advisor** — The only first-party advisory agent. It recommends; it
does not authorize.

**Canonical state** — SQLite current state plus hash-chained append-only events.

**Capability** — An executable unit Shiroe may invoke only after lifecycle,
digest, adapter, and policy checks pass.

**Generated view** — A Markdown projection rebuilt from canonical state.

**Handoff artifact** — A scrubbed JSON or Markdown package compiled from Work
Graph, approval, memory, and verification state.

**Human-only approval** — Approval records can be decided only by an explicit
human action and are bound to a deterministic scope digest.

**Reasoning class** — Provider-neutral routing class: `fast`, `balanced`,
`deep`, `frontier`, `local`, or `private`.

**Verification Engine** — The runtime surface for privacy, evidence, fact,
contradiction, semantic review, write, and graph checks.

**Work Graph** — The sole operational graph model for work nodes, dependencies,
readiness, attempts, and lifecycle state.
